Data sources

Using data in graphics

Click a cell to copy its reference, then paste it into a text field or a text layer:

{{Match!B2}} the cell B2 of "Match"
{{Match!Team#3}} the "Team" column, 3rd row
{{Match!Score}} the cell next to "Score" in column A

{{time}} {{time24}} {{date}} the clock; {{countdown:19:30}} the time left until 7:30 PM.

Export HTML

Graphics as plain web files that play without the engine: a browser source, CasparCG or SPX template (play / stop / update), or a web page. The values on Preview are used.

In the zip, open index.html. Add ?autoplay=0 to wait for play(), ?Field=Text to set a field, or ?live=http://this-pc:8782 to follow this engine's Program.
